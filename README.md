# Somewhere

*Let it find you.* A dating game set in Singapore: explore streets, do things together, follow the string.

- Godot 4.7 (GL Compatibility). Open `project.godot` in Godot and press Play.
- Multiplayer: `render.yaml` + `Dockerfile` run the relay server on Render (free). The web build connects to it.
- See `CLAUDE.md` for how the project is laid out.
- Fonts: Inter and Fraunces, SIL Open Font License (see `fonts/`).
